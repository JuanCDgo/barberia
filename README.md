# 💈 Micro App Barbería & Barbershop

Aplicación web ligera (HTML + Vanilla JS + Tailwind CSS) para barberos y barberías independientes en Argentina.

## Características
- 💈 Gestión de clientes de barbería (Corte Fade, Base Navaja/Shaver/Cero, Barba perfilada, Color/Platinado).
- 💬 Recordatorios por WhatsApp en 1 toque adaptados para WhatsApp Desktop y móvil.
- ⏰ Alertas automáticas según frecuencia de corte (1, 2, 3 o 4 semanas).
- 📅 Turnero Online opcional para que los clientes elijan su día y horario solos.
- 📷 Soporte para subir Logo o Foto de la Barbería con compresión automática en vivo.
- 💵 Control de saldos y señas con indicador discreto de punto verde.
- ☁️ Sincronización automática de copias de seguridad con Google Drive (Carpeta: *Copia de seguridad Barberias*).
- 📊 Exportación a planilla Excel / Google Sheets y descarga JSON local.
